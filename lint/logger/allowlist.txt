# Allowlist for lint/logger/cmd/loglint.
#
# Format: one entry per line, "<key>  # <reason>". A blank line or a
# whole-line "#" comment is ignored. The key identifies a checked
# constructor or method that takes a zap logger as a parameter:
#   - a constructor:      <path>:<FuncName>
#   - a method:            <path>:<RecvTypeName>.<MethodName>
#
# A reason after "#" is mandatory — an entry without one fails the lint run.
#
# This file is a debt ledger, not a permanent exemption list. When a listed
# constructor or method is migrated to the options pattern, its violation
# disappears from the scan and the corresponding row becomes stale. A stale
# entry is itself a lint failure, so paying down the debt requires deleting
# the row — the ledger is self-cleaning by construction.
